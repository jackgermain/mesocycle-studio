# Jacked — Template Library

Every template that ships in the app: **125 programs**, 3524 exercise slots, 10,011 working sets.

Each is one week. The week repeats for the whole block — load progresses, the layout doesn't. Loads are deliberately blank: the template is a muscle-order skeleton, and what someone lifts is theirs.

> Generated from the shipped app bundle. Renames, edits or deletions made inside the app live in the database and are **not** reflected here.
