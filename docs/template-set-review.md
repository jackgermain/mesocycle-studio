# Jacked — Template Set Review

Weekly sets for all 125 shipped templates.

**Direct** = sets where that muscle is the primary mover. **Effective** = direct plus fractional synergist credit (back work pays biceps, pressing pays triceps and front delts), which is why effective can be far higher than anything actually written into the program.

The 10–25 reference band is the app's general guidance, not a pass mark: a specialty template is *meant* to run its target muscle hot, and a partial template (upper-only, lower-only) is *meant* to be light everywhere else.
